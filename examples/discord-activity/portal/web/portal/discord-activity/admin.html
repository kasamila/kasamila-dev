  1. Activities → Settings：启用 Activities。OAuth2 → Redirects 添加官方 Activity 示例使用的 https://127.0.0.1 占位地址。
  2. Activities → URL Mappings 按下表配置，根路径 / 放最后，Target 不包含 https://，必须映射到目录。
