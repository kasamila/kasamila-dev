# Kasamila 语音伴侣 0.4.1（浏览器扩展预览版）

桌面 Chrome / Edge 116+，Manifest V3。在用户选定的 HTTPS 网页（或 localhost）点击扩展按钮，将该页声音用于驱动 Kasamila 数字人。不限定 ChatGPT，网页朗读、AI 回复和其他可捕获音频均可使用。提示音、音乐也会被捕获。受保护媒体、浏览器内部页面和手机浏览器不在支持范围内。

## 使用

1. 解压后，在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载 `extension` 文件夹，并将 Kasamila 固定到工具栏。
2. 在声音来源网页点击扩展图标或 `Alt+Shift+K`，直接打开约 280 × 330 的置顶小窗；可以手动拖动和调整大小。
3. 首次在小窗中选择数字人、阅读并确认音频处理同意，点击“启用数字人”。配置保存在当前浏览器，下次点击扩展图标自动连接。
4. 小窗右上角 ⚙ 打开配置；更换角色后点击“启用数字人”。配置时释放旧推理会话，网页音频捕获保持运行。取消勾选同意会取消下次自动连接。■ 停止捕获和推理。底部亮点表示捕获到网页声音。
5. 全程只有这一个置顶小窗，无大窗、画面镜像、窗口迁移或自动接回。静音、回复结束及同页路由切换不结束会话。关闭小窗、关闭来源页或完整刷新/导航导致来源文档销毁时，会停止；重新点击工具栏即可按保存配置连接。Admin 的会话时长、并发及频率限制仍有效。
6. 原网页的麦克风和对话操作照常使用。原声仅播放一次，数字人自身关闭重复音频播放；它跟随网页声音，不生成回答。

**升级到 0.4.1**：关闭旧伴侣窗口，覆盖扩展文件，在扩展管理页点击“重新加载”，然后在声音来源网页点击工具栏图标。若浏览器要求确认新增权限，请确认后启用。仅刷新网页不会更新扩展。

## 数据与权限

链路：`所选标签页 → tabCapture → offscreen AudioWorklet → 小窗内的扩展 iframe → Kasamila 同源嵌套页面 → 现有 SDK`。

- `activeTab` / `tabCapture`：仅在用户点击后访问并捕获选定标签页的音频。
- `offscreen`：持续处理音频并保持原声播放。
- `scripting`：点击工具栏时向所选页注入隔离脚本，仅用于创建置顶窗口。不读取页面文字、账号或应用内部接口，不自动注入其他网页。
- `storage`：本地保存数字人 ID、音频同意和配置版本。无音频、对话内容、密钥或 Runtime Token 持久存储。

没有全站主机权限、麦克风权限或远程扩展脚本。仅将 `panel.html` 声明为可嵌入资源；后台只接受本次用户操作所创建小窗的随机标识。Portal 消息桥固定校验扩展父窗口及 Kasamila Origin。远程 SDK 保留同源父窗口，Runtime Token 不经过扩展消息桥。

16 kHz PCM16 使用 40ms 包，最多 8 个待确认包；超时确认自动回收，积压不会永久堵住后续声音。独立心跳保证静音时不会因 MV3 空闲回收而主动结束连接。

## Portal 与 Admin

默认连接 `https://kasamila.com/portal/apps/companion/embed`。Admin → 应用演示管理中配置专用 Runtime Key、启用语音伴侣，并为公开数字人勾选“用于语音伴侣”。无需配置语音模型。此扩展使用托管演示额度，并非无限免费推理。

仅单窗嵌入模式会将经校验的来源网页 Origin 加入该响应的 CSP 祖先列表；音频驱动仍在官网 Origin 下使用现有短期 Runtime Token，不扩大推理 Key 域名白名单。无永久密钥进入浏览器。

自行托管须保留同意、Origin、额度、心跳与断开清理边界。Portal 实现位于 `kasamila_api/modules/portal/companion.py` 和 `web/portal/companion*`，API/SDK 无需修改。

## 验证

隔离浏览器测试通过真实工具栏动作获取权限，覆盖 WebRTC 音频、首次同意、保存后自动连接、36 秒静音、丢失确认恢复、来源窗最小化、设置和停止。浏览器保留后台节流。另用真实托管 Runtime 和已发布 SDK 检查口型、音频时钟及渲染帧，不只判断画面加载成功。测试不保证所有网站或网络环境均兼容。

这是手动安装预览版，尚未上架 Chrome Web Store / Edge Add-ons。数字人口型有捕获和推理延迟。

0.4.1：修复保存配置后启动时无法恢复被浏览器暂停的音频初始化。允许自动播放时继续自动连接；受限时小窗会显示“点击继续连接”，无需进入设置或更换数字人。启动超时可直接重试，取消时清理尚未完成的 Runtime。关闭浏览器后只保留数字人和同意选项，每次打开都申请新会话。
